Example 3: Complex Assignment Description

Full example with markdown and math:

Python Functions Assignment

Write a function to calculate the area of a circle with radius $r$.

The formula is:

$$A = \pi r^2$$

where:

  • $A$ is the area
  • $r$ is the radius
  • $\pi \approx 3.14159$

Requirements:

  1. Return result rounded to 2 decimal places
  2. Handle case when $r \leq 0$
